# Design

## Context
Почасовые данные уже загружаются сервером и отображаются клиентом.
Черновик не меняет исходный контракт прогноза.

## Goals / Non-Goals
Goals: объяснить будущий путь погодной подсказки.
Non-Goals: push-уведомления, фоновое расписание и реализация кода в этом изменении.

## Decisions
Клиент получает существующий прогноз, выделяет дождливые часы и выводит подсказку.
Новый сетевой запрос не нужен. Альтернатива с отдельным сервером уведомлений
не соответствует узкому объёму этой идеи.

## Risks / Trade-offs
При ошибке прогноза подсказка недоступна; текущая погода остаётся доступной.
