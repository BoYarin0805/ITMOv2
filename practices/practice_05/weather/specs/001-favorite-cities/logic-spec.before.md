# Исходное предложение логики

Хранить до пяти мест в браузере. Идентичность — координаты, а не имя.
Операции: прочитать список, добавить выбранное место, удалить по идентификатору.
Проверять координаты и имя, отбрасывать дубликаты.

Предлагаемый конверт: `{version:1,cities:[{id,name,latitude,longitude}]}`.
До согласования с UI не определены точность ID, поведение при запрете записи,
обработка отдельных повреждённых записей и возможность добавления до загрузки погоды.
