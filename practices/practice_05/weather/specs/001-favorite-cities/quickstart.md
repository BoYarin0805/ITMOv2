# Проверка

Запустить `python3 server.py`, открыть сайт. Выбрать город → «В избранное» →
перезагрузить → выбрать запись → удалить. Текущая карточка после удаления сохраняется.

Ошибки: шестой город, повтор координат, повреждённый JSON и отказ storage.
`node --test tests/test_favorites.cjs`; сквозные сценарии — `npm run test:browser`.
