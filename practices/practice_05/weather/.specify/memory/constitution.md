# Weather Constitution

Версия 1.0.0, принята 29 октября 2026.

1. Требования и контракт UI/логики согласуются до реализации.
2. Текущая погода, прогноз и демонстрация явно различаются. Нет фиктивных live-данных.
3. Python standard library + vanilla JS; runtime без сторонних зависимостей.
4. Публичное поведение проверяется тестами; сеть в unit-тестах подменяется явно.
5. Сбой внешнего API или браузерного хранения не должен разрушать независимые сценарии.
6. Все исходники и инструменты локальны папке пятой практики. Глобальные настройки не меняются.
7. Проверки не ослабляются ради PASS. Выводы отчёта подтверждаются командами и артефактами.
