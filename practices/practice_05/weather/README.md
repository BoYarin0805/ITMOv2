# Небо — погода в движении

Я сделал погодный сайт для практики 5: реальные текущие условия, почасовой прогноз,
избранные города и видеопейзажи под погоду, сезон и время суток.

![Интерфейс](evidence/desktop.png)

## Запуск

```bash
cd practices/practice_05/weather
python3 server.py
```

Открыть **http://127.0.0.1:8055**. Нужны Python 3.12 и Node.js для автоматических
проверок. Runtime работает без pip/npm-пакетов. Для Open-Meteo нужен интернет,
API-ключ не требуется. Страница инструментов: `/tools.html`.
Перезапуск: Ctrl+C → `python3 server.py`, затем Ctrl+Shift+R в браузере.

## Возможности

- Поиск городов с выбором региона/страны, четыре готовых города.
- Текущая температура, ощущаемая температура, влажность, ветер и время источника.
- 24 ближайших полных часа: время города, температура, состояние и предпросмотр.
- До пяти избранных мест в браузере; понятное предупреждение при отказе хранения.
- Шесть локальных футажей WebM/MP4 с постерами, сезон южного/северного полушария,
  дождь/снег/ночь, пауза и reduced motion. Пейзажи иллюстративные, не камеры города.
- Явные режимы «Реальные данные», «Прогноз» и «Демонстрация».

## Проверки

```bash
make test                         # Python + JavaScript, без внешней сети
make install-tools                # локальные OpenSpec и Chromium
make browser                      # 8 сквозных браузерных сценариев
make openspec-check               # строгая проверка текущих specs и draft
python3 -B scripts/live_smoke.py   # реальные погода и прогноз Open-Meteo
```

Dev-зависимости закреплены в package-lock.json; инструменты и кэши устанавливаются
внутри проекта. Для первого browser-запуска нужен интернет для скачивания Chromium.
Ожидаемый результат: **29 Python + 10 JavaScript + 8 браузерных сценариев — PASS**.
Браузерные тесты используют явные фикстуры, реальная сеть проверена отдельно.

## Структура

`server.py` — HTTP и погодный источник, `forecast.py` — нормализация часов/DST,
`static/` — интерфейс и футажи, `tests/` — проверки, `openspec/` и `.specify/` —
SDD-материалы, `evidence/` — результаты и скриншоты.
