# Правила проекта

1. День/ночь и тип погоды — независимые признаки: снег возможен и ночью.
2. Тестовые сценарии меняют панель, а не реальные данные города.
3. Внешний ввод проверяется до сетевого запроса. Ошибка API не превращается в нулевую температуру.
4. HTTP и MCP используют общие функции поиска и получения погоды из `server.py`.
5. Не ослаблять runner или контрольные сценарии ради PASS. Новые пакеты для небольшой задачи не добавлять.

Пример: `weatherState(71, 0)` возвращает `snow` и `Ночь`.
Проверка: skill `weather-state-check` и `sh scripts/check.sh`.
