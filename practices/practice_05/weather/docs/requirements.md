# Этап 1: условия приёмки

1. В браузере по адресу http://127.0.0.1:8055 открывается минимальный сайт.
2. Можно выбрать Санкт-Петербург, Москву, Казань или Сочи и получить текущие
   расчётные погодные условия Open-Meteo для соответствующих координат.
3. Карточка показывает город, температуру и ощущаемую температуру (°C), влажность (%),
   ветер (м/с), описание погоды, день/ночь, время данных и часовой пояс города.
4. Во время запроса показана загрузка. При ошибке источника видна ошибка и можно
   повторить запрос. Данные прежнего города не показываются как данные нового.
5. Есть ссылка на источник; тестовые значения на рабочем сайте не используются.

За пределами этапа: произвольный поиск, демонстрационные режимы, прогноз,
MCP, skill, hook, OpenSpec и декоративный интерфейс.

## API

- `GET /api/cities` → `{"cities": [{"id": "spb", "name": "Санкт-Петербург"}, ...]}`.
- `GET /api/weather?city=spb` → город, `current`, `units`, `timezone`, `source`.
- Неизвестный город: 400 с `error`. Сбой источника: 502 с `error`.
- `GET /api/health` → `{"status": "ok"}`.

Документация провайдера: https://open-meteo.com/en/docs
Время данных возвращается в часовом поясе города (`timezone=auto`).

# Этап 2: согласованные фичи A и B

## A: поиск города

- Поиск по названию от 2 до 100 символов, русские названия поддерживаются.
- Результат содержит название, регион (если есть), страну и координаты.
- Пользователь явно выбирает результат. Погода запрашивается для его координат.
- Нет совпадений, ошибка источника и некорректный ввод различаются.
- Более старый ответ поиска/погоды не перезаписывает более новый результат.
- Готовые города и ручное обновление сохраняются.

API: `GET /api/search?q=Выборг`; для найденного города
`GET /api/weather?latitude=60.7&longitude=28.75&name=Выборг`.
Координаты должны быть конечными числами: широта -90…90, долгота -180…180.

## B: погодное состояние и демонстрация

- Панель показывает ясно/облачно/дождь/снег/туман/гроза, символ и день/ночь.
- Неизвестный погодный код явно показывается как неизвестное состояние.
- При загрузке/ошибке реальные состояния прошлого города не сохраняются в панели.
- Демо: ясно днём, ясно ночью, облачность, дождь, снег ночью, туман, гроза.
- Деморежим явно подписан и влияет только на панель; реальные погодные числа не меняются.
- Демо работает без доступа к погодному источнику. Возврат к реальному режиму
  показывает последнюю загруженную погоду либо отсутствие текущих данных.

Поиск использует Open-Meteo Geocoding: https://open-meteo.com/en/docs/geocoding-api
