## Изменение OpenSpec

Добавляю почасовой прогноз и просмотр выбранного часа. Данные прогноза запрашиваются
отдельно от текущих условий: отказ прогноза не должен скрывать текущую карточку.
Результаты относятся к координатам выбранного города; более старые ответы игнорируются.

Решения до кода:
- Горизонт — 24 ближайших полных часа, начиная с первого часа не раньше времени
  `current.time` источника. Запрашивается 3 дня, чтобы хватило часов после полуночи.
- Время — местное время города, часовой пояс подписан. Сравниваются ISO local time
  в рамках одного ответа источника, без преобразования через часовой пояс компьютера.
- Показываю температуру, WMO-состояние и день/ночь. Предпросмотр не меняет реальные числа.
- При отсутствии 24 корректных часов прогноз возвращает отдельную ошибку, не фиктивные данные.
- Настройку OpenSpec проверю на черновике связанного изменения, без его реализации.

## Вторая фича (ДЗ, GitHub Spec Kit)

Избранные города в localStorage: до пяти, выбор и удаление. Она использует текущие
координаты и тот же загрузчик погоды. Для неё сначала подготавливаются отдельно
спецификации UI и логики, затем общий контракт, план и задачи.
Сбой localStorage не должен ломать поиск и текущую погоду.
