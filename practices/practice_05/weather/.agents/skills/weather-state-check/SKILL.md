# Проверка погодных состояний

Работай из корня `practice_05/weather`. Сначала прочитай `AGENTS.md`,
`docs/requirements.md` и `docs/style-guide.md`.

1. Прочитай [контрольные сценарии](references/cases.json). Они задают ожидаемое
   поведение независимо от реализации. Не получай ожидания вызовом проверяемой функции.
2. Запусти `node .agents/skills/weather-state-check/scripts/check.cjs`.
   Скрипт сравнивает реальные результаты `weatherState` с матрицей и запускает
   проверки взаимодействия деморежимов с карточкой реальной погоды.
3. При FAIL укажи вход, ожидание и факт. Не меняй ожидания, чтобы скрыть ошибку.
   Исправления требований сначала согласуй с пользователем.
4. После доработки выполни `sh scripts/check.sh`; сопоставь результат
   с `docs/requirements.md`. Для проверки в браузере предложи снег ночью → реальная погода.

Последний результат скрипта сохраняется в `.runtime/skill.json`. Полный набор
автотестов не заменяет просмотр интерфейса пользователем.
