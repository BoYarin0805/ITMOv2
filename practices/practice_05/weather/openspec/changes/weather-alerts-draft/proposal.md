## Why

Будущий пользователь сможет заранее заметить дождь. Это учебный черновик для
проверки постоянного правила OpenSpec, реализация в текущую работу не входит.

## What Changes
- Планируется текстовая подсказка о дожде на основе уже полученного прогноза.
- Сейчас изменяются только документы; API, интерфейс и код не расширяются.

## Capabilities
### New Capabilities
- `weather-alerts`: будущая текстовая подсказка о дождливом часе.
### Modified Capabilities
Нет.

## Impact
Только черновик OpenSpec. Будущая реализация потребует отдельного поручения.
