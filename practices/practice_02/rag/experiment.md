## Запрос

> Ответь только по четырём источникам из таблицы. Для каждого ключевого утверждения в UC-1 укажи ссылку и тип: правило задания, наблюдение в diff или проектное предложение. Отдельно назови решения без основания. Не привлекай веб, предположения о FastAPI или отсутствующие файлы приложения. Подготовь компактную таблицу для `product_management.md`.

## Ответ со ссылками на источники

Один diff, формат ответа и полномочия человека заданы [README](../../practice_01/README.md#задача-помощника). Существующее обращение к `payload["diff"]` и ответ `comment` видны в [diff](../../practice_01/TRAINING_PR.diff). Валидация, структурированный ответ и проверка ссылок предложены [ADR](../../practice_01/adr.md#решение). Точный JSON нового ответа, лимит и код сбоя остаются открытыми по [Context Pack](../../practice_01/context.md#что-пока-неизвестно) и ADR.
