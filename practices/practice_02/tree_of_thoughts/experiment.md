# Tree of Thoughts

- Решение, для которого нужны альтернативы: что показывать человеку, если модель вернула смесь рисков с верными и отсутствующими ссылками на diff.
- Критерии выбора: **доказательность** (не показывать ложную ссылку), **полезность** (не терять проверяемые замечания), **ясность состояния** (человек видит, что часть вывода исключена). Каждый критерий оценивается 0–2; сумма до 6.
- Вход: [ADR-001](../../practice_01/adr.md#решение), [UC-1](../../practice_01/product_management.md#use-case-uc-1-получить-черновик-ревью).

## Запрос

> Предложи ровно три независимых способа обработать ответ LLM, где один риск ссылается на существующую строку diff, а второй — на отсутствующую. Оцени каждый по доказательности, полезности и ясности состояния (0–2 по каждому). Выбери правило для учебного прототипа и предложи проверку с fake LLM. Сохрани решение человека по PR и не выдавай наличие строки за доказательство причинности.

## Варианты решения

| Альтернатива | Плюсы | Минусы | Оценка по критериям |
|---|---|---|---|
| A. Вернуть весь текст с предупреждением | Сохраняет все предложения | Ложная ссылка остаётся перед ревьюером как риск | 0 + 2 + 1 = **3/6** |
| B. Отклонить весь ответ модели | Ложная ссылка не показывается | Теряется корректное замечание; причина отказа может быть ясной | 2 + 0 + 2 = **4/6** |
| C. Исключить неверный риск и сообщить причину | Сохраняет проверяемое замечание, явно показывает частичность | Требуется валидатор и правило для случая, когда исключены все риски | 2 + 2 + 2 = **6/6** |

## Выбор

- Выбранная альтернатива: C; если исключены все кандидаты, показать неопределённость и не выдавать пустой список за успешную проверку.
- Почему: она удовлетворяет всем трём критериям и сохраняет ручную проверку причинности. Баллы — качественная проектная оценка агента, не экспериментальные измерения.
- Как проверим: fake LLM возвращает один риск `app/api.py:10` и один `app/api.py:999`; в черновике остаётся первый, второй исключён с причиной. Во втором опыте возвращаются только отсутствующие ссылки; интерфейс показывает неопределённость.
