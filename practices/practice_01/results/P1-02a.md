# P1-02a — предварительный изолированный запуск

Инструмент: Codex, отдельный субагент без истории рабочего чата и без инструментов. Модель: унаследована от текущей сессии, та же, что в P1-01; точный идентификатор интерфейсом не раскрыт. Вход: только TRAINING_PR.diff и сокращённая передача восьми разделов [Master Prompt v1](../prompts.md#master-prompt-v1). Ответ сохранён без исправлений.

---

## Изменение

Добавлены `ReviewService.review`, который передаёт diff модели и возвращает её ответ в поле `comment`, и маршрут `POST /api/reviews`, вызывающий этот метод.

## Риски

1. `app/api.py:10` — маршрут обращается к `payload["diff"]` без проверки наличия ключа → для тела `{}` возникнет `KeyError`; последствия для HTTP-ответа зависят от неизвестной внешней обработки ошибок → проверить запрос с `{}`.

## Проверки

- Передать `ReviewService.review` строку diff и подставить LLM, возвращающую `"замечание"`; ожидать вызова `generate` с prompt, содержащим diff, и результата `{"comment": "замечание"}`.
- Отправить `POST /api/reviews` с `{}`; проверить, что обращение к отсутствующему ключу вызывает `KeyError`, и зафиксировать фактический ответ API. Проверки не выполнялись.

## Неизвестно

Неизвестны контракт для пустого тела, внешняя обработка ошибок, ограничения размера diff и поведение модели. Число видимых строк в обоих hunks не совпадает со счётчиками их заголовков; ссылка `app/api.py:10` получена подсчётом видимых строк новой версии.
