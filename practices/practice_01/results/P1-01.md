# P1-01 — исходный ответ изолированного запуска

Инструмент: Codex, отдельный субагент без истории рабочего чата и без инструментов. Модель: унаследована от текущей сессии; точный идентификатор интерфейсом не раскрыт. Вход: только TRAINING_PR.diff и запрос из [журнала](../prompts.md#журнал). Ответ сохранён без исправлений.

---

Нашёл три проблемы:

- **P1 — содержимое diff может подменить инструкцию модели** ([app/review_service.py:14](/home/boyarin/ITMOv2/practices/practice_01/app/review_service.py:14)). Diff вставляется в prompt без отделения от инструкции. Автор PR может добавить в файл текст вроде «игнорируй предыдущую задачу», и модель примет его за указание вместо материала для проверки.
- **P1 — размер diff ничем не ограничен** ([app/api.py:9](/home/boyarin/ITMOv2/practices/practice_01/app/api.py:9)). Один большой запрос может превысить контекст модели или вызвать дорогой и долгий вызов. Нужен предел размера до обращения к LLM.
- **P2 — некорректный payload приводит к ошибке сервера** ([app/api.py:10](/home/boyarin/ITMOv2/practices/practice_01/app/api.py:10)). При отсутствии `diff` будет `KeyError` и ответ 500; значения другого типа тоже проходят без проверки. Схема запроса со строковым обязательным полем даст клиенту корректный ответ 422.
