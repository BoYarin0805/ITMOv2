# Правила работы с Notify Mini

Перед изменениями прочитай `docs/requirements.md` и `docs/style-guide.md`. Выполняй только описанные фичи A и B. Проект использует стандартную библиотеку Python, дополнительных пакетов нет.

Для работы над фичами загрузи skill `notify-tdd` через инструмент `skill`, затем запускай его скрипт для нужной фичи. Перед завершением вызови MCP tool `notify_checks_run_checks` с `suite: "all"`. После каждой правки автоматически запускается hook с `sh scripts/check.sh`; исправь ошибки, если проверка не прошла.

Не меняй файлы в других практиках. Добавляй тесты на поведение, включая неверный ввод. Проверяй итог командой `sh scripts/check.sh`.
