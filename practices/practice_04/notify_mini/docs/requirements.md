# Требования

В памяти хранится множество имён подписчиков. Имена — непустые строки после удаления пробелов по краям. Регистр сохраняется; повторная подписка не создаёт дубль.

## Фича A: отписка

Метод `unsubscribe(name)` удаляет существующего подписчика и возвращает `True`. Если имени нет, возвращает `False`. Неверное имя вызывает `ValueError`; состояние при этом не меняется.

## Фича B: список

Метод `list_subscribers(prefix="")` возвращает новый список подписчиков в лексикографическом порядке. Непустой префикс очищается от пробелов по краям. Пустой префикс показывает всех. Не-строковый префикс вызывает `ValueError`. Вызов не меняет состояние.
