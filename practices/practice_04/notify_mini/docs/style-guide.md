# Стиль

1. Публичные методы имеют короткий docstring с контрактом результата.
2. Валидация входа выполняется до изменения состояния.
3. Не добавлять зависимости для задачи, решаемой стандартной библиотекой.
4. Тесты группируются по фичам и проверяют как успешный, так и ошибочный сценарий.
5. Проверка должна запускаться одной командой: `sh scripts/check.sh`.
